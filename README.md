## 🏥 Clinical Tools

### 🌙 [Toranot](https://github.com/Eiasash/Toranot) — On-call ward management
Hebrew PWA for on-call geriatric ward shifts at SZMC. WhatsApp/nurse-call list parser, 58 rule groups for auto-generated tasks, **Beers Criteria 2023**, **STOPP/START v3**, drug interactions, KDIGO AKI staging, anticholinergic burden, falls risk, renal dosing for 22+ antibiotics, structured handoff (ISBAR), Claude-powered clinical reasoning. → [toranot.netlify.app](https://toranot.netlify.app)

### 🏨 [ward-helper](https://github.com/Eiasash/ward-helper) — SZMC ward rounds copilot
Hebrew-RTL mobile-first PWA. Camera AZMA screen → reviewed Hebrew note → paste to Chameleon. BYO Anthropic key, encrypted Supabase backup.
